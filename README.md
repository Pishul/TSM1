## 🎯 What Is This?

An AI-powered study assistant for **Thermodynamics & Statistical Mechanics I**. The AI agent is constrained by [[AGENTS|strict rules]] to deliver exam-quality answers based **only** on the course materials in this vault.

### ✨ Key Features
- **📚 Source Prioritization:** Answers come from `lecture_notes/`, `textbook/`, and `Home_Works/`
